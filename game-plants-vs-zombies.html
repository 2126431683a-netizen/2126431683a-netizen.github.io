06 / Casual · Lane Defense

《植物大战僵尸》系列

一块草坪、几条路线，看上去简单得不能再简单。可阳光一紧、僵尸一换路，阵容马上就得重想。它把理解成本压得很低，却没有把策略空间一起削掉。

Core Question

不写长教程，
玩家怎么学会策略

规则直接长在画面里：植物是什么功能、僵尸从哪来、哪条路要守，一眼就能看到。失败以后，调整方向也同样清楚。

  • 核心体验轻量策略
  • 主要预算阳光 / 格子 / 冷却
  • 信息结构横向路线
  • 学习方式边玩边懂
休闲不是把所有判断删掉，而是让玩家不用先读说明书，就能开始做判断。
A / Readability

功能几乎写在角色身上

向日葵产资源，坚果阻挡，豌豆射手输出。外形、动画和功能彼此一致，玩家不必记住抽象术语。

B / Budget

阳光让每次放置都有代价

现在补输出还是先做经济，便宜单位还是高价核心，资源预算让看似简单的放置持续产生取舍。

C / Lane

路线把复杂战场压成可读信息

威胁来自哪一行非常清楚，玩家能快速判断缺口，也能直观看见一次部署是否解决了问题。

D / Teaching

一次只加一个新问题

新植物、新僵尸、夜晚、泳池逐步出现。单个规则不难，组合起来却不断迫使旧阵容作出变化。

Round Loop

一局里不断重复的判断

信息简单，取舍却一直没有停。

01 / 观察

先看威胁从哪条路来

僵尸类型和路线直接暴露当前最急的问题。

02 / 预算

阳光该投经济还是防线

短期安全与长期产能不断发生冲突。

03 / 放置

阵容落地后立刻看到结果

射程、阻挡和伤害都通过画面清楚表现。

04 / 调整

意外出现时重新分配资源

新僵尸或路线压力推动阵容动态变化，而不是摆完就等。

Design Takeaway

带回休闲与塔防设计

容易理解，不代表缺少值得推敲的选择。

01

视觉先替系统解释规则

单位功能、攻击方向和目标优先级尽量从外形与动画里读出来，减少额外说明成本。

02

每关只突出一个新矛盾

新内容逐层组合，而不是一次性把所有规则扔给玩家。

03

失败后要知道换什么

是资源节奏不对、路线漏防，还是阵容克制不足，原因越清楚，重试意愿越强。
