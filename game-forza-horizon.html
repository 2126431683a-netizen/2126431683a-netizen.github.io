05 / Racing · Open-world Festival

《极限竞速：地平线》系列

好手感只负责第一脚油门。真正让人一再上路的，是公路尽头的新风景、不断扩大的车库，以及“再开一场就下线”的轻巧节奏。

Core Question

不只比赛，
为什么一直想开车

驾驶本身足够舒服，地图又持续提供短目标。即便没打算参加赛事，开向下一个地方也已经成立。

  • 核心体验驾驶自由
  • 内容容器开放世界嘉年华
  • 成长来源车辆与技术
  • 社交压力轻比较
一辆车先得“听话”，玩家才愿意继续理解它。门槛和深度可以同时存在，只是别在第一分钟一起砸下来。
A / Handling

辅助系统先保证爽感

不同水平的玩家都能快速感到速度和控制。辅助降低入门挫败，却没有抹平车辆、路线与调校之间的差异。

B / Map

赶路本身就是内容

道路、地形、天气和可破坏环境不断改变驾驶状态。从一场赛事去下一场赛事的路，不只是加载条。

C / Collection

车库把短局接成长线

新车既是奖励，也是新的操作体验和身份表达。收集不只增加数字，而是在持续扩展可玩的方式。

D / Festival

嘉年华消解竞技压力

广播、音乐和活动把输赢包进庆典氛围里。玩家可以认真竞速，也可以只是开车看风景，参与感不必只来自排名。

Drive Loop

从一脚油门到下一辆车

爽感、目标和成长很快接成一条线。

01 / 选车

先决定今天想怎么开

车型和调校预先定义速度、地形与操控倾向。

02 / 上路

地图沿途不断抛出目标

赛事、测速、探索和偶遇让路线随时可以改变。

03 / 完赛

成绩给技术一个刻度

路线和操作能被复盘，进步不只表现为车辆数值。

04 / 扩展

奖励打开新的驾驶方式

新车辆、新赛事与新地区继续扩大下一轮选择。

Design Takeaway

带回低门槛、高上限设计

先让核心操作舒服，再逐层释放复杂度。

01

第一分钟必须建立信任

输入、反馈和结果保持一致，玩家先觉得“系统听我的”，才愿意学习更深规则。

02

成长奖励最好改变玩法

新内容不只是更高数值，还应提供新的路线、节奏或操作体验。

03

允许不同强度的参与

高水平玩家追求成绩，休闲玩家也能通过探索与收集获得完整回报，系统不用逼所有人走同一条路。
