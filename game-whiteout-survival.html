07 / Mobile SLG · Social Strategy

《无尽冬日》

最初上线是为了收资源、升火炉、清队列；等联盟活动和队友时间表接进来以后，留下来的理由就不再只是一串战力。它用轻量包装，把玩家一步步带进了很深的 SLG 关系网。

Core Question

一次升级，
怎么变成每天上线

短目标负责给出确定进展，等待队列负责制造回访时点，联盟则把个人成长变成一件和别人有关的事。

  • 视觉锚点火炉与营地
  • 短期目标建造 / 养成 / 任务
  • 长期结构联盟 / 活动 / 竞争
  • 回访机制时间队列
红点能提醒一次，关系才能留下很久。联盟里有没有人等着一起做事，往往比下一次升级更重要。
A / Hearth

火炉把抽象成长变得可见

冰雪环境持续制造生存压力，火炉等级则直观代表安全和文明进度。核心建筑因此不只是数值节点，也是情绪锚点。

B / Queue

等待时间安排回访节奏

建造、训练和研究把目标切成不同长度。玩家离开前已经知道什么时候值得回来，日常节奏因此被系统预先安排。

C / Growth

多条成长线互相制造缺口

建筑、英雄、装备和科技持续争夺资源。总有一条线接近下一次提升，也总有另一条线提醒资源还不够。

D / Alliance

联盟把数值变成社会位置

帮助、集结和活动让战力不再只是个人成绩。上线时间、分工和共同目标逐渐建立责任感，也形成更难被替代的留存理由。

Retention Layers

从几分钟到几个月

不同时间尺度的目标层层接住玩家。

01 / 分钟

收取与升级立刻给反馈

资源到账、建筑变化和战力增长形成短周期满足。

02 / 小时

队列预告下一次回访

离线等待不是空白，而是已经预约好的下一步。

03 / 天

活动和任务安排日常节奏

固定目标让成长方向保持清楚，也推动资源持续循环。

04 / 周月

联盟与竞争承接长期关系

共同目标、排名和服务器格局把个人进度放进更大的社会结构。

Design Takeaway

带回长线运营设计

先让每次上线有事做，再让这些事和别人产生关系。

01

短目标必须够得着

每次打开游戏都能完成一件事，玩家才会相信进度一直在向前走。

02

等待要提前告知回报

队列开始时就明确结束时间与收益，等待才是计划，不是卡住玩家。

03

社交目标承接个人成长

联盟活动应让不同强度的成员都有位置，避免社交只剩高战力玩家的舞台。

04

警惕数值膨胀盖过主题

当升级只剩数字变化，冰雪生存的独特感会迅速变薄。视觉、事件与玩法要持续提醒玩家为何建设这座营地。
