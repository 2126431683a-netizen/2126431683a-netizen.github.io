03 / Narrative Game

雾港疑云

像素风悬疑叙事游戏，从两幕网页原型继续扩展到 Unity 三幕四结局版本。变量、收集和解谜共同决定玩家看见哪一层真相。

Role / Scope

游戏策划
叙事与系统

负责三幕结构、分支变量、角色对话、场景调查、信件收集、解谜、结局条件和 Unity 迁移规则。

  • 版本Web / Unity 2022.3
  • 类型像素悬疑叙事
  • 网页边界两幕原型
  • Unity 边界三幕完整版本
A / Branch

双变量控制关系与真相

真相度决定玩家掌握的信息层级，镇民信任影响对话开放与协助意愿，两者共同进入结局判定。

B / Collect

信件不是装饰性收集

5 封哥哥来信分别补足人物动机，并作为隐藏结局的必要证据，让探索行为改变叙事结果。

C / Puzzle

解谜服务于信息重组

拼报、场景调查和对话线索复用同一证据逻辑，玩家通过重组碎片推进，而不是完成无关小游戏。

D / Save

按幕保存关键状态

幕级检查点记录变量、信件和关键选择，保证分支可恢复，也为多结局复玩控制重复成本。
