# 放开那个女巫 · 官方网站

> 改编自同名小说与热门动漫的奇幻魔法世界官方网站 — 概念设计展示

线下地址：https://2126431683a-netizen.github.io/

## 项目简介

本站是《放开那个女巫》的官方概念展示网站，包含游戏介绍、精神世界、魔女图鉴、活动公告、预约表单等板块，采用暗色魔法视觉风格（玻璃拟态、橙紫渐变、星芒动画）。

## 功能板块

- **游戏介绍**：世界观与核心玩法概述
- **精神世界**：女巫意识链接与魔力共振的设定展示
- **魔女图鉴**：8 位角色（罗兰、安娜、夜莺、莉莉、温蒂、凯特、伊芙琳、闪电）的可切换循环轮播卡片，支持自动播放与悬停预览动画
- **活动公告**：最新活动与官方资讯，可跳转至独立活动详情页
- **立即预约**：邮箱预约表单

## 公告 CMS 使用说明

本站采用 **GitHub 驱动 CMS**：所有活动公告数据集中存储在 `assets/activities.json`，前端（首页公告区 + 活动详情页）动态读取渲染，无需改 HTML 即可更新公告。

### 在线管理（推荐）

1. 打开管理后台：`admin.html`
2. 填入你的 GitHub 个人访问令牌（需 `repo` 写权限；令牌仅保存在本机浏览器，不上传服务器）
3. 即可在网页上新增 / 编辑 / 删除公告，写回 GitHub 后刷新前端页面即生效

### 手动编辑

直接修改 `assets/activities.json` 并提交推送即可，前端自动同步。

## 部署

本站部署于 GitHub Pages，分支 `main`。推送 `index.html` 及 `assets/` 目录后自动发布。

## 技术栈

- 纯静态 HTML / CSS / JavaScript，无构建依赖
- CSS 变量 + 玻璃拟态 + 渐变动画
- GitHub Contents API 驱动公告数据读写
- 响应式设计，适配桌面与移动端
