03 / Action · Skill Mastery

《只狼》

它最狠的地方不是难，而是总能把“菜在哪”说得很清楚。格挡时机、架势变化、危险提示和命中声音一起工作，让每次失败都留下下一轮能用的信息。

Core Question

难度怎么变成
学习的动力

玩家愿意重试，不是因为惩罚够重，而是因为已经看见下一次做对的可能。

  • 核心体验正面对刀
  • 主要资源架势与生命
  • 学习对象节奏和前摇
  • 关键反馈声音 / 火花 / 危提示
早了、晚了、还是贪了？输完能立刻回答这个问题，死亡就不只是惩罚。
A / Deflect

防御本身就是进攻

精准格挡会累积敌方架势，玩家不必在“保命”和“输出”之间来回切换。正面对抗因此始终保持主动感。

B / Posture

架势把节奏变成可见资源

连续压制能够加速处决，退缩又会让优势回落。系统鼓励稳定地留在战斗里，而不是打一刀就绕场逃跑。

C / Readability

失败原因被多通道放大

前摇、红色危字、火花与声音共同提示攻击性质。信息足够清楚，玩家才会把失败归因到自己的判断，而不是系统不讲理。

D / Exam

Boss 是阶段考试，不是突击考

前面敌人教过的识破、踩头、格挡和距离判断，会在 Boss 身上重新组合。难度上升，但题目并非凭空出现。

Learning Loop

一次失败怎样变成进步

信息必须在几秒内完成回收，否则情绪只剩挫败。

01 / 试探

先看敌人的节奏

通过一两次交锋识别前摇、连段和危险攻击。

02 / 判断

选择格挡、识破或闪避

不同攻击要求不同回应，不能只靠一个万能动作。

03 / 反馈

声音和火花立刻判卷

操作是否准确，不必等到血量结算后才知道。

04 / 修正

带着一个明确问题重来

下一轮只需修正一个节点，学习曲线便能持续推进。

Design Takeaway

带回战斗系统设计

公平感来自信息，而不是降低所有难度。

01

敌人出招必须可读

《暮鸦之墓》要先明确前摇、范围和命中时机，再考虑增加速度和伤害。

02

正确操作需要即时确认

命中、闪避和格挡的声音、画面与数值反馈应保持一致，避免玩家猜系统有没有生效。

03

Boss 复用已经教过的规则

挑战来自组合和节奏变化，而不是临时加入一套从没出现过的解法。
