01 / Played & Studied

玩过什么，
又留下了什么

比起把游戏名堆成一张清单，我更想记住那些真正起作用的设计：目标是怎么立住的，重复为什么不腻，以及哪些东西值得带回自己的项目。

Open World / Soulslike

《艾尔登法环》

最着迷的是它很少催着玩家赶路，却总能用远处的城堡、赐福和若隐若现的小路勾出下一站。开放世界真正迷人的地方，果然不是塞满图标，而是让人发自内心地想说一句：“那边好像有东西，去看看。”

空间引导风险回报探索节奏

Action RPG / Cultural Adaptation

《黑神话：悟空》

真正留下印象的，不只是 Boss 打得爽，而是场景、音乐、演出和传统文化常常在同一个节点一起发力。它证明了地图不必无限铺大，只要章节有自己的情绪和记忆点，一段路也能走出完整的旅程感。

Action / Skill Mastery

《只狼》

《只狼》最狠的地方，不是难，而是它总能把“菜在哪”说得很清楚。早按、晚按、贪刀、没看懂前摇，输完几乎立刻知道下一轮该改什么。于是死亡不再只是惩罚，反而成了最直接的教学。

Narrative RPG / Quest Design

《巫师 3：狂猎》

很多支线接起来像一件小事，走到最后却很难轻松收场。角色各有理由，选择也很少干净利落。相比奖励本身，这种“做完以后还会想一会儿”的余味，才是任务真正留住人的地方。

Racing / Open-world Festival

《极限竞速：地平线 3 / 4 / 5 / 6》

把几代串起来看，会发现好手感只负责第一脚油门，真正让人一再上路的，是季节、地图、车辆收集和嘉年华共同营造的出发欲。新手开得爽，老玩家又有调校和路线可钻研，这个分层做得很漂亮。

Casual / Lane Defense

《植物大战僵尸》系列

一块草坪、几条路线，规则看上去简单得不能再简单。可一旦阳光不够、僵尸换路，阵容马上就得重想。几乎不用读教程，失败一次便会主动换植物，这种“看得懂、想得深”的轻量感很值得研究。

02 / Genre Lab

一种乐趣，到底是怎么成立的

先看玩家为什么愿意开始，再追踪几十秒里反复做的选择。最后回头看失败反馈和长期内容，有没有自然地把人带进下一轮。

8 个类型拆解

01 / Action

魂系动作：为什么还想再来一次

参考：《艾尔登法环》《只狼》《黑神话：悟空》

高难度不是卖点。失败要是带不回一条有用的信息，下一次挑战就只剩消耗。
核心吸引
从陌生和畏惧，一步步走到真正掌握敌人
短循环
观察前摇、判断应对、执行操作，再根据反馈修正
主要压力
动作窗口、治疗资源、死亡成本和阶段变化同时出现
内容组织
普通敌人教规则，精英做小测，Boss 完成阶段考试

落到项目里：《暮鸦之墓》优先明确敌人前摇、攻击冷却、命中反馈和复生泉回收点。难可以，但得让玩家看得懂自己输在哪里。

02 / Open World

开放世界：目的最好由玩家自己长出来

参考：《艾尔登法环》《巫师 3》《极限竞速：地平线》系列

比起清图标，更期待远景、道路和偶发事件不断抛来一句：“都到这儿了，要不绕过去看看？”
核心吸引
自主发现目标、选择路径，并看到世界作出回应
短循环
发现远景、规划路线、遭遇事件，再顺着奖励找到新线索
主要压力
路程、资源、未知风险和重复内容持续消耗耐心
内容组织
主路径稳住节奏，支路制造惊喜，安全区留出重新决策的空间

落到项目里：《暮鸦之墓》先把世界收敛成主城、野外和副本，用安全度与收益差异验证路线选择。节奏成立以后，再谈地图要不要继续做大。

03 / Racing

开放竞速：再开一段，就一段

参考：《极限竞速：地平线 3 / 4 / 5 / 6》

速度和风景负责把人吸引进来，车辆收集、路线熟练度和朋友间的比较，才负责把人留下。
核心吸引
立刻获得驾驶爽感，同时慢慢建立对车辆的理解
短循环
选车、找路线、完成赛事、拿奖励，再尝试新的驾驶目标
主要压力
抓地、速度、弯道、地形和对手节奏不断要求取舍
内容组织
辅助驾驶降低门槛，调校、路线和车辆差异打开成长空间

落到设计里：新玩家最好在一分钟内就感到“这辆车听我的”，之后再用车型、地形和赛事规则慢慢加深。入口要爽，深度不能急着全倒出来。

04 / Narrative

叙事驱动：做过的事，应该留下痕迹

参考：《巫师 3》《黑神话：悟空》

剧情不该只是战斗之间的世界说明书。角色关系和后续处境有没有被行动改变，才决定选择有没有重量。
核心吸引
理解角色，并为自己的判断承担情绪后果
短循环
获得线索、形成判断、采取行动，再通过结果更新关系
主要压力
信息不完整、价值冲突、选择成本和节奏中断
内容组织
主线确认方向，支线深化世界，环境信息填补留白

落到项目里：《雾港疑云》用真相度和镇民信任记录行动后果。结局来自一路积累的判断，而不是临到最后突然弹出一个决定命运的按钮。

05 / Casual

休闲玩法：一眼看懂，不代表一局玩完

参考：《植物大战僵尸》系列

休闲不等于简单。它只是把理解成本放低，再把组合空间和节奏变化藏在后面，等玩家自己发现。
核心吸引
快速进入状态，并在短时间内得到完整反馈
短循环
观察威胁、分配资源、放置单位、处理意外，再调整阵容
主要压力
有限格子、阳光预算、路线威胁和冷却时间相互挤压
内容组织
第一局教会动作，后续关卡再逐步引入组合冲突

落到设计里：轻量玩法先保证规则能从画面和结果里直接读出来，再用新单位、新路线和资源变化扩展重玩空间。别急着上长教程，先让玩家动起来。

06 / Competitive

FPS 竞技：枪法之外，局势怎么读

重点观察：枪线、地图控制、队伍信息和交火后的局势重建

枪法能赢下一次交火，但想稳定地赢，还是得读懂信息、位置和团队节奏。
核心吸引
在公平对抗里不断提高决策与执行上限
短循环
收集信息、抢占位置、完成交火，再重新判断局势
主要压力
视野盲区、时间窗口、经济差和队友信息差同时存在
内容组织
地图承载路线博弈，武器形成距离分工，回合规则建立节奏

落到设计里：玩家被击倒时，至少要能看明白自己输在哪一步：是没听到脚步、没架住枪，还是队友信息没对齐。这套基础没打稳之前，急着堆新角色和新武器，只会让问题更难排查。

07 / Strategy

回合与策略：资源不够，选择才有意思

设计验证：《放开那个女巫》《三国文字合成塔防》

策略感不来自规则有多少，而是资源确实有限、答案不止一个，而且每个选择都得付出看得见的代价。
核心吸引
通过预判、配置和资源安排，把劣势慢慢扳回来
短循环
读取局势、分配资源、执行动作，再根据变化调整方案
主要压力
行动点、冷却、位置、经济和不可逆投入相互冲突
内容组织
基础关教单规则，组合关制造冲突，Boss 迫使配置变化

落到项目里：《放开那个女巫》用 3 AP 控制回合预算；《三国文字合成塔防》则让金币、粮食和 8 条合成线长期抢资源。取舍得真疼，策略才站得住。

08 / Mobile SLG

《无尽冬日》：短目标怎么长成长期关系

参考：《无尽冬日》

最初为了下一次建筑升级上线，后来真正决定留不留下的，往往是联盟里还有没有人等着一起完成目标。
核心吸引
看着营地持续变强，同时在联盟里找到明确位置
短循环
收资源、升建筑、养英雄、参加活动，再回到下一轮等待
主要压力
时间队列、资源缺口、战力比较和联盟协作成本
内容组织
火炉做视觉锚点，活动控制节奏，联盟承接长期留存

落到运营里：每次上线先给一个够得着的小目标，再让联盟目标承接个人成长。只靠红点和数值膨胀把人叫回来，久了只剩疲惫。

03 / Global Readiness

同一款游戏，
到了不同市场以后

本地化绝不是上线前把文本翻译一遍。玩法信息、UI 空间、文化语境、付费习惯和社区运营，都应该更早进入版本计划。

US / CA

美国 / 加拿大

新手目标和付费信息要说得直白，玩家花的钱买到了什么，不能靠猜。与此同时，分级、隐私、无障碍和节日语境都得在上线前过一遍。

  • 任务与技能文案更直接
  • 提前检查 ESRB、隐私与无障碍要求
  • 商店素材展示真实玩法
JP

日本

把中文换成日文，只完成了最表面的一层。角色称谓、语气层级、文本换行和配音情绪都要重看一遍，人物关系才不会在翻译后突然变味。

  • 统一人名、称谓与世界观术语
  • 按日文字符重新验证 UI 密度
  • 结合当地内容节奏安排预热与社区沟通
KR

韩国

技能说明、概率规则和竞技公平最好讲得更透明；中端 Android 设备、网络波动和版本更新速度，则直接影响一款游戏能不能长期跑稳。

  • 明确展示数值、概率与规则变化
  • 优先检查性能、发热和弱网体验
  • 为社区反馈建立更快的回收路径
DE / FR

德国 / 法国

英文版本不能永远当兜底方案。德语文本更长，法语有自己的表达习惯，GDPR 和退款说明又会直接碰到 UI 与发行流程，这些都得提前进入验收。

  • 为德语膨胀预留按钮和字幕空间
  • 法语追求自然表达，不做逐字替换
  • 让数据授权与删除路径清楚可见
SA / UAE

沙特 / 阿联酋

阿拉伯语不是把文字右对齐就结束了。RTL 布局要从头走一遍，服装、宗教、社交表达和斋月活动语境也应在策划阶段检查，而不是临上线再删内容。

  • 按从右到左重新验证完整操作流
  • 提前完成文化与素材风险审查
  • 结合当地节日调整活动节奏和奖励表达
ID / TH

印度尼西亚 / 泰国

这里最现实的问题往往不是内容够不够多，而是设备带不带得动、安装包大不大、弱网下能不能顺利进游戏。先跑得动，再谈规模。

  • 把首包、热更和内存列为核心指标
  • 验证本地支付与价格分层
  • 让客服和社区运营真正进入本地语言环境

适配顺序：先排查文化与合规风险，再处理语言和 UI；随后验证设备、付费和活动节奏，最后用商店、社区与数据反馈继续修正版本。

04 / Analysis Method

平时怎么拆游戏

先找到玩家真正追求的结果，再逐层检查系统有没有服务这个结果。方法不复杂，关键是每一层都能落到可观察的体验。

01

先找承诺

选择这类游戏时，玩家最想得到的那种独特感受是什么。

02

再跑循环

记录 30 秒到 3 分钟内，哪些判断和动作正在反复发生。

03

定位压力

拆开时间、空间、资源、信息和操作，看它们怎样迫使玩家取舍。

04

检查内容

看关卡、任务、敌人和奖励如何分阶段教学，又如何完成检验。

05

回看反馈

确认成功与失败是否讲清原因，并自然带出下一个目标。

玩过的体验，
最后都要变成可执行的设计判断。
