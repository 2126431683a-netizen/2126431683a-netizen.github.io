04 / Narrative RPG · Quest Design

《巫师 3：狂猎》

不少支线从一份委托开始，最后却把玩家推到一个没有标准答案的位置。角色都有自己的理由，选择也很少干净利落。做完以后还会想一会儿，这才是任务真正的余味。

Core Question

支线为什么不像
奖励的包装盒

因为任务的核心不是跑腿，而是逐步改变玩家对人物、事件和世界规则的理解。

  • 核心体验判断与后果
  • 叙事入口委托 / 传闻 / 偶遇
  • 主要张力信息不完整
  • 长期回报世界状态变化
选择不是两个按钮，而是前面收集过的信息、相信过的人，以及愿不愿意承担之后的结果。
A / Hook

先从一件具体小事进入

失踪、怪物或家庭纠纷都足够清楚，玩家很快知道眼前要做什么。复杂性不在开头堆设定，而在调查过程中慢慢出现。

B / Motive

对立双方都有能理解的理由

人物不是为了推动任务才犯错。动机和处境足够具体，玩家才会犹豫，而不是一眼识别“正确选项”。

C / Consequence

后果不急着当场揭晓

有些结果要隔一段时间才重新出现。延迟让选择更像世界的一部分，也让玩家意识到任务结束并不等于事情结束。

D / World

支线反过来解释世界

一条委托可能揭开战争、贫困、种族或权力结构。它的价值不只是经验值，而是让世界变得更可信。

Quest Arc

一条支线怎样越走越深

从明确目标进入，再一点点打破最初判断。

01 / 接入

先给一个能立刻理解的委托

玩家清楚要找谁、查什么，进入成本保持足够低。

02 / 调查

线索开始互相矛盾

新的信息逐步动摇第一印象，判断空间随之打开。

03 / 选择

没有完全无损的答案

每条路径都保护一些东西，也必然牺牲另一些东西。

04 / 回响

结果在世界里留下痕迹

人物、场景或后续对话持续提醒玩家那次决定发生过。

Design Takeaway

带回分支叙事设计

变量要记录过程，而不只是最后一选。

01

角色动机先于选项数量

《雾港疑云》先让每个镇民拥有清楚的诉求和隐瞒，再决定分支如何展开。

02

过程变量负责积累后果

真相度和镇民信任记录一路上的调查与关系，不把结局压缩成最后一刻的按钮。

03

支线也要改变世界理解

每条支线至少补充一个人物、一条规则或一层历史，否则很容易退化成奖励清单。
