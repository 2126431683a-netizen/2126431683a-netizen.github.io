02 / ARPG Vertical Slice

暮鸦之墓

不是先铺一张大地图，再往里填功能。我先用主城、野外和副本划分风险节奏，再把任务、战斗、成长与移动交互接成可运行的 ARPG 垂直切片。

查看完整 GDD查看画面

Role / Scope

独立游戏策划

负责世界规则、任务、近战、敌人 AI、装备成长、副本、触控与工程风险拆解。

  • 引擎Godot 4.3
  • 类型3D 开放世界 ARPG
  • 交付Vertical Slice
  • 平台Android
A / World

三类区域承担不同节奏

安全主城负责接取与整备，开放野外负责探索和随机遭遇，封闭副本负责高强度挑战与首通奖励。

B / Loop

任务形成可重复闭环

目标追踪、导航、采集、击杀、背包条件和交付结算共用一套状态规则，避免任务只是一段对话。

C / Combat

动作反馈必须可判定

斩击和重击拥有独立伤害、范围、冷却与命中反馈；普通敌人与 Boss 采用不同强度层级。

D / Mobile

触控不是键鼠直接搬运

分离摇杆与镜头区域，控制拇指可达范围、弹窗输入阻断和 20:9 安全区，并按 P0/P1/P2 验收。
