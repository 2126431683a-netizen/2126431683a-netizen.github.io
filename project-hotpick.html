A / User

从内容运营的时间压力出发

目标用户不是“需要 AI 的所有人”，而是每天处理热点、平台差异和排期的一线内容运营。

B / Score

评分帮助筛选而非代替判断

以时效性、平台适配和选题延展三个维度评价热点，同时保留来源、标签和受众信息供人工判断。

C / Convert

同一热点生成多平台方案

围绕账号定位、内容目标与风格参数，分别生成 B 站、小红书和公众号方向，并标记优先级。

D / Loop

复盘结果回到选题判断

收藏、评论、完播和转化不只出现在看板，而是回流到题材标签与评分模型，形成持续调整闭环。
